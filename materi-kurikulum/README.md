## Cara Pakai (LLM)

- Import otomatis: `python backend/import_kurikulum.py` akan upsert semua MD ke DB `materi` (source_type=builtin).
- Generate soal: `POST /api/generate-question` otomatis filter `jenjang+kelas+mapel` → ambil konteks dari bank ini.
- Ujian bab: `POST /api/ujian/generate` dengan `materi_tersedia` per bab.
